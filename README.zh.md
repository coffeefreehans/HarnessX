# DeepSeek HarnessX

当前公开版本为 **0.1**，界面品牌为 **HARNESSX**。DeepSeek HarnessX 是固定版本 DeepSeek Harness 的独立桌面客户端，提供原生窗口、系统托盘、配置切换、本地终端、插件市场、安装任务和 GitHub Release 应用更新。

Windows 提供 x64 与 ARM64 安装包，macOS 提供 Intel x64 与 Apple Silicon ARM64 安装包。绿色 ZIP 仅用于本地测试，不上传公开 Release。完整的下载、运行、配置、安全边界、打包和许可说明直接写在 [README.md](README.md) 中。
